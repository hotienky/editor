# kindy-editor

Canvas-rendered Word-accurate document editor.


## Packages

- `@kindy/shared` — Document model, ops, OT (pure data, no DOM)
- `kindy-editor` — Embeddable editor library

## Development

```bash
npm install
npm run dev   # → http://localhost:5173/
```
